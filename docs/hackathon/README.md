# Hackathon pitch materials (archived)

These files were written for the Grand Challenge judging rounds and are kept
here unedited, as a record:

- [GRAND_CHALLENGE_PITCH.md](GRAND_CHALLENGE_PITCH.md): the pitch, organized
  by the judging criteria
- [FINAL_SUMMARY.md](FINAL_SUMMARY.md): demo script and pre-demo checklist

They're pitch documents, not technical documentation. The market sizes,
revenue projections, competitor comparisons, success metrics, accuracy claims
and self-assigned scores in them are hackathon projections. Nothing in this
repo backs them up.

For what the code actually does, see the [project README](../../README.md),
[detection-services.md](../detection-services.md) and
[video-frame-extraction.md](../video-frame-extraction.md).
